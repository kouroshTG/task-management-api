# سامانه مدیریت وظایف | Task Management API

یک REST API برای مدیریت وظایف (Tasks) با استفاده از **Python و FastAPI** که با هدف یادگیری مفاهیم مهندسی بک‌اند و ساخت یک پروژه قابل ارائه در رزومه توسعه داده شده است.

این پروژه شامل احراز هویت کاربران، مدیریت وظایف، کنترل دسترسی، فیلتر و جست‌وجو، صفحه‌بندی و اجرای کانتینری با Docker است.

## امکانات

### احراز هویت و کاربران
- ثبت‌نام کاربران
- ورود و دریافت توکن JWT
- مشاهده اطلاعات پروفایل کاربر
- هش امن رمز عبور با الگوریتم Argon2
- مدیریت دسترسی به منابع بر اساس هویت کاربر

### مدیریت وظایف
- ایجاد، مشاهده، ویرایش و حذف وظایف (CRUD)
- تعیین وضعیت وظیفه:
  - `pending`
  - `in_progress`
  - `completed`
- تعیین اولویت:
  - `low`
  - `medium`
  - `high`
- تعیین تاریخ سررسید (Due Date)
- فیلتر بر اساس وضعیت و اولویت
- جست‌وجو در عنوان و توضیحات وظایف
- صفحه‌بندی نتایج با استفاده از `limit` و `offset`

### امنیت و کنترل دسترسی
- احراز هویت مبتنی بر JWT
- هش رمز عبور با Argon2
- محدودسازی دسترسی کاربران به وظایف متعلق به خودشان
- جلوگیری از دسترسی، ویرایش یا حذف وظایف سایر کاربران
- اعتبارسنجی ورودی‌ها با Pydantic

### زیرساخت و کیفیت کد
- مدیریت پایگاه داده با SQLAlchemy 2
- مدیریت تغییرات ساختار دیتابیس با Alembic
- اجرای پروژه با Docker و Docker Compose
- تست خودکار با Pytest
- بررسی کیفیت و استاندارد کد با Ruff

## معماری پروژه

ساختار پروژه با تفکیک مسئولیت‌ها طراحی شده است:

```text
app/
├── api/
│   ├── dependencies.py
│   └── v1/
│       ├── endpoints/
│       └── router.py
├── core/
│   ├── config.py
│   └── security.py
├── db/
│   ├── base.py
│   └── session.py
├── models/
├── repositories/
├── schemas/
└── services/

migrations/
tests/
```

مسئولیت لایه‌ها:

- **API:** تعریف Endpointها و دریافت درخواست‌های HTTP
- **Services:** پیاده‌سازی منطق کسب‌وکار
- **Repositories:** مدیریت عملیات دسترسی به داده‌ها
- **Models:** تعریف مدل‌های دیتابیس
- **Schemas:** اعتبارسنجی ورودی و خروجی API
- **Core:** تنظیمات و قابلیت‌های امنیتی
- **DB:** مدیریت اتصال و نشست‌های دیتابیس
- **Migrations:** مدیریت تغییرات ساختار دیتابیس
- **Tests:** تست رفتار و صحت عملکرد برنامه

## راه‌اندازی با Docker

### پیش‌نیازها

- Docker
- Docker Compose

### ۱. دریافت پروژه

```bash
git clone https://github.com/kouroshTG/task-management-api.git
cd task-management-api
```

### ۲. ایجاد فایل تنظیمات

```bash
cp .env.example .env
```

مقادیر فایل `.env` را متناسب با محیط خود تنظیم کنید. به‌خصوص مقادیر زیر:

- `POSTGRES_PASSWORD`
- `SECRET_KEY`

برای تولید یک کلید تصادفی امن می‌توانید از دستور زیر استفاده کنید:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

### ۳. اجرای سرویس‌ها

```bash
sudo docker compose up --build -d
```

### ۴. بررسی وضعیت سرویس‌ها

```bash
sudo docker compose ps
```

### ۵. مشاهده مستندات API

پس از اجرای موفق برنامه، مستندات Swagger از آدرس زیر در دسترس است:

http://localhost:8000/docs

همچنین می‌توانید از مستندات ReDoc استفاده کنید:

http://localhost:8000/redoc

### توقف سرویس‌ها

```bash
sudo docker compose down
```

برای مشاهده لاگ‌ها:

```bash
sudo docker compose logs -f api
```

## اجرای تست‌ها

برای اجرای تست‌ها در محیط توسعه، ابتدا محیط مجازی را فعال و وابستگی‌های توسعه را نصب کنید.

```bash
pip install -e ".[dev]"
```

سپس تست‌ها را اجرا کنید:

```bash
pytest -q
```

برای بررسی کیفیت کد:

```bash
ruff check app tests
```

## مستندات API

این پروژه از API نسخه‌بندی‌شده با پیشوند زیر استفاده می‌کند:

```text
/api/v1
```

برای مشاهده جزئیات Endpointها، پارامترها، ساختار درخواست و پاسخ‌ها از Swagger استفاده کنید:

http://localhost:8000/docs
